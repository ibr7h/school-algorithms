# مصمم المخططات الانسيابية المدرسي

تطبيق تعليمي باللغة العربية لرسم المخططات الانسيابية، وتحويل أمثلة بايثون إلى مخططات، والتحقق من بنية الرسم، ومحاكاة التنفيذ خطوة بخطوة.

## تشغيل التطبيق
- **الموقع:** https://ibr7h.github.io/school-algorithms/
- **الكود:** `index.html` (يتضمن المحرر والأدوات والتنسيق المتجاوب).
- يعمل في متصفح الكمبيوتر والتابلت والهاتف، مع أدوات جانبية للأجهزة الصغيرة ودعم السحب والتكبير باللمس.

## المحاكاة التعليمية
1. افتح **محرر بايثون** وأدخل برنامجًا بسيطًا.
2. اختر **إضافة مخطط جديد في نفس المنطقة**.
3. اضغط **▶ محاكاة التنفيذ** من شريط المشروع.
4. اختر المخطط، ثم **التالي** أو **تشغيل**، وراقب المتغيرات والمخرجات.
5. عند ظهور `input()` أدخل القيمة من لوحة المحاكاة.

### النطاق الحالي
يدعم تحليل ورسم `if / elif / else`، و`for` و`while` و`break` و`continue`، وتعليمات طباعة وإسناد أساسية. المحاكاة تعليمية **وليست تشغيلًا فعليًا لمفسّر Python**؛ بعض التعابير والبنى غير مدعومة ويجب عدم الاعتماد عليها للتحقق من جميع برامج Python. تقف المحاكاة عند 500 خطوة.

المخططات المُدخلة يدويًا أو المُستوردة من Graphviz ليست قابلة للمحاكاة دون بيانات برمجية مرتبطة بها.

## حفظ المشروعات
يحفظ التطبيق البيانات في المتصفح محليًا. للتنقل بين الأجهزة أو للاحتفاظ بنسخة احتياطية، استخدم **حفظ مشروع JSON** ثم **فتح مشروع**. يحافظ تصدير SVG على عرض المخطط، لكنه ليس بديلاً عن ملف JSON للتحرير والاستعادة.
