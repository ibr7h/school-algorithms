# مصمم الخوارزميات المدرسية

تطبيق عربي لتصميم المخططات الانسيابية وتحويل أمثلة Python إلى مخططات، مع أداة فحص بنيوية، وتعدد مناطق العمل، وتصدير SVG.

## التشغيل

افتح `index.html` محليًا أو عبر GitHub Pages. الرسم يدعم الكمبيوتر والتابلت والجوال. بيانات العمل تحفظ محليًا في المتصفح، ويمكن تصدير نسخة JSON.

## حدود حالية

تحويل Python يدعم مجموعة محددة من تعليمات الشروط والحلقات والطباعة؛ ولا ينفّذ Python اعتباطيًا. بعض الموارد تحتاج الإنترنت.

## النشر

ينشر Workflow في `.github/workflows/pages.yml` عند الدفع إلى `main`، بعد تفعيل GitHub Pages ومصدر GitHub Actions في إعدادات المستودع.
